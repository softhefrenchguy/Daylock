# Daylock delivery preferences

The user wants completed Daylock changes on GitHub every time. After implementing and validating requested changes, commit and push them to the existing GitHub repository without asking for confirmation again, unless the user gives a contrary instruction.

Phone-test APKs should be attached to a draft GitHub release while physical-device testing is pending. Do not publish a new public release before physical-device testing is complete. Report the pushed commit and, when an APK is provided, its draft release link.
